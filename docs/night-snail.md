# Night Snail

Night Snail is a short game about a snail wandering through a forest at night.

夜の森で、星の光を避けながら薔薇を集めるスネイルの物語。
プレイの軌跡が、詩と音楽になります。

## Play

[Play / Download on itch.io](ITCH.IOのURL)

## About

約100秒のプレイのなかで、移動、音楽、言葉がそれぞれ別の規則で動きながら影響し合います。

日本語 / English 対応。
Web / Windows / macOS。
